# Example - coding style

This is a placeholder showing the format Ultron expects. Delete it once you've added your own preferences, or keep it as a template.

- Prefer TypeScript over plain JavaScript for new projects.
- Never force-push to `main` without asking first.
- Deploy to staging before production, always — no exceptions, even for "tiny" fixes.
- Keep commit messages under 72 characters on the summary line.
